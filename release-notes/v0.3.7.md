## 亮点

- **模型设置一步直达**：点卡片上的「模型设置」直接在该卡片内展开模型列表，不经弹窗、不再要求先保存余额配置。
- **支持明文 HTTP 上游**：裸 IP 网关也能接入了（设 `DSH_BALANCE_ALLOW_HTTP=0` 可恢复仅 HTTPS）；SSRF 防线（公网校验、固定 IP、禁重定向、凭据拒绝）全部保留。

## 体验改进

- **引入供应商直接出卡片**：点菜单项立即保存并显示新卡片，地址猜错时再进「余额设置」微调。
- **错误信息瘦身 + 全中文化**：上游 HTML 错误页只显示摘要与状态码中文提示（如 `HTTP 404（该地址不存在，请核对余额查询地址）`），不再整页贴标签；Host 层残留的 6 条英文报错全部本地化。
- 余额设置弹窗两页（余额 / 健康监测）的页脚与表单外壳样式统一，操作行固定不随内容滚动。

## 修复

- 保存后卡片跳到列表末尾——Host 与前端共 4 处 upsert 全部改为保序替换。
- 未配置余额的供应商点保存报 `invalid provider identity`：现在自动补齐可保存草稿，只填一个地址即可。
- 点「取消」没反应、上次的报错红字残留到下次打开弹窗。
- 脱敏正则两个边界缺陷：不再吞掉周边展示文本；补齐 `API key:`（空格）、`apiKey=`（驼峰）及 `sk-`/`pk-`/`rk-` 裸密钥兜底，堵住凭据泄露口。
